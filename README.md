# DataLab — Лаборатория данных

Интерактивный образовательный проект «Типы и виды данных». Автор проекта — Русинов Давид, 11 «А» класс, 2026.

## Открытие

Откройте `index.html` в браузере. Все страницы и функции статические: сервер, регистрация и сборка не нужны. Для стабильного сохранения прогресса рекомендуется локальный HTTP-сервер или GitHub Pages.

Локальный просмотр при установленном Python:

```sh
python -m http.server 8000
```

Перейдите на http://localhost:8000.

## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое папки DataLab** в корень репозитория: `index.html`, остальные HTML-страницы, `assets`, `.nojekyll` и этот README.
3. В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`, затем Save.
4. После завершения публикации откройте адрес, показанный в Pages.

Все внутренние ссылки относительные: сайт работает как в корне домена, так и по адресу `username.github.io/repository/`. Файл `.nojekyll` отключает обработку Jekyll. Сайт ещё не опубликован: для публикации нужен выбранный репозиторий пользователя.

## Лаборатория

1. Определение типа: `int`, `float`, `str`, `bool`, `list`, `tuple`, `dict`, `set`.
2. Преобразование в `int`, `float`, `str`, `bool` с объяснением ошибок.
3. Создание, изменение и удаление переменных; учебная модель памяти.
4. Сравнение определений, операций, особенностей и применения любых двух типов.
5. Пошаговая симуляция пяти подготовленных программ с изменением входных значений.

Парсер не использует `eval`, `Function` или исполнение произвольного Python. Это ограниченный учебный синтаксис, а не полный Python: поддерживаются десятичные числа, обычные строки с базовыми escape-последовательностями и вложенные коллекции. Не поддерживаются выражения, вызовы функций (кроме литерала `set()`), `None`, комплексные числа, тройные кавычки, префиксы строк, числовые основания и произвольный код. Целые числа ограничены диапазоном ±(2^53 − 1); длина ввода — 4000 символов, глубина вложенности — 20. Отрицательное `//` округляется вниз, преобразование float в int — к нулю.

Модель памяти не имитирует реальные адреса, размеры или сборку мусора Python. Переменные хранятся только во время открытой страницы.

## Прогресс и доступность

Ключ localStorage: `datalab.v1`. Сохраняются тема, посещение учебных разделов, выполненные эксперименты, верно решённые задания и лучший результат теста. Это локальные данные этого браузера; синхронизации между устройствами нет. При запрете хранилища сайт продолжает работать без сохранения.

Баллы начисляются один раз за каждое решённое задание. Итоговая оценка: 9–10 правильных — 5, 7–8 — 4, 5–6 — 3, 0–4 — 2.

Интерфейс поддерживает клавиатуру, видимый фокус, подписи полей, уведомления для экранных дикторов, сенсорные кнопки и `prefers-reduced-motion`. Внешний запрос используется только для шрифтов Google Fonts; без интернета работают системные шрифты и все симуляторы.

## Проверка

Проверены граничные случаи парсера, ошибки преобразования, отрицательное деление, повторяющиеся элементы множеств, запрет нехешируемых ключей и отсутствие исполнения кода. Страницы проверены на компьютере и мобильном размере. Основные сценарии лаборатории, практика, навигация теста, результат и повторное прохождение проверены в браузере.

В совместимых браузерах лаборатория также предоставляет WebMCP-инструмент анализа литерала. Проверены регистрация, обновление видимого результата и отказ на недопустимом вводе. В остальных браузерах эта возможность автоматически пропускается.
